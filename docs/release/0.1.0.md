# BeamNG Eliminator v0.1.0 — Architecture Foundation

**Release date:** 2026-11-23  
**Status:** Foundation scaffold; not a playable game mode.

## Included

- Initial server-plugin and client-mod directory layout.
- Server-side match manager, roster and network boundary placeholders.
- Client extension, network boundary and AI prototype placeholder.
- Versioned shared protocol envelope and initial match constants.
- Offline Python structural/configuration tests.
- Local Windows and Linux packaging scripts.
- Initial MIT license and architecture documentation.

## Not included

- No playable lobby or spawn-selection UI.
- No live BeamMP event handlers.
- No synchronized AI vehicles or AI driving.
- No vehicle drops, head-to-head races, arena contraction or final showdown.
- No claim of successful in-game compatibility testing.

## Verification

The release is intended to be checked with the local test and build scripts, then installed on a disposable BeamMP test server and BeamNG client for integration work.
